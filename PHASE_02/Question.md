
# 16. CODING PRACTICE QUESTIONS

Solve these problems yourself before checking solutions.

## LEVEL 1 — FOUNDATION

1. Print every character of a string.
2. Find the length of a string without using len().
3. Access the first and last characters.
4. Reverse a string.
5. Check whether a string is empty.
6. Count vowels.
7. Count consonants.
8. Count digits and alphabets.
9. Convert lowercase to uppercase.
10. Convert uppercase to lowercase.
11. Find the ASCII/Unicode value of a character.
12. Remove all spaces.
13. Count the number of words.
14. Check whether a character exists.
15. Replace a particular character.

## LEVEL 2 — CHARACTER FREQUENCY

16. Count the frequency of every character.
17. Find the maximum frequency character.
18. Find the minimum frequency character.
19. Find the first non-repeating character.
20. Find the first repeating character.
21. Remove duplicate characters.
22. Print duplicate characters.
23. Count occurrences of a particular character.
24. Find all character positions.
25. Sort characters by frequency.

## LEVEL 3 — PALINDROME AND ANAGRAM

26. Check whether a string is a palindrome.
27. Check a palindrome ignoring spaces.
28. Check a palindrome ignoring punctuation.
29. Check whether two strings are anagrams.
30. Group anagrams.
31. Find the longest palindromic substring.
32. Count palindromic substrings.
33. Check valid palindrome after deleting one character.
34. Check whether two strings are rotations.
35. Find the longest common prefix.

## LEVEL 4 — STRING SEARCHING AND MANIPULATION

36. Find a substring without using find().
37. Implement naive pattern searching.
38. Implement KMP.
39. Reverse every word in a sentence.
40. Reverse the order of words.
41. Compress a string.
42. Check whether one string is a subsequence of another.
43. Check whether two strings are isomorphic.
44. Find the longest word in a sentence.
45. Find the longest substring without repeating characters.

## LEVEL 5 — ADVANCED

46. Minimum Window Substring.
47. Longest Repeating Character Replacement.
48. Valid Parentheses.
49. Decode String.
50. Edit Distance.
51. Longest Common Subsequence.
52. Longest Common Substring.
53. String to Integer (atoi).
54. Rabin-Karp Algorithm.
55. Wildcard Pattern Matching.
