# 15. INTERVIEW QUESTIONS WITH ANSWERS

## Q1. What is a string?

A string is an immutable sequence of Unicode characters used to represent text.

## Q2. Are strings mutable in Python?

No. Python strings are immutable.

## Q3. What is string indexing?

Indexing is the process of accessing individual characters using their positions.

## Q4. What is negative indexing?

Negative indexing accesses characters from the end of the string.

## Q5. What is slicing?

Slicing extracts a portion of a string using start, stop and step.

## Q6. What is the difference between find() and index()?

`find()` returns -1 if the substring is missing, whereas `index()` raises ValueError.

## Q7. What is concatenation?

Combining two or more strings into one string.

## Q8. What is the difference between split() and join()?

`split()` converts a string into a list, whereas `join()` combines strings into a single string.

## Q9. What is a palindrome?

A sequence that reads the same forward and backward.

## Q10. What is an anagram?

Two strings containing the same characters with identical frequencies.

## Q11. What is character frequency?

The number of times each character appears in a string.

## Q12. What is hashing?

Hashing maps data to a hash value and allows efficient average-case lookup using structures such as dictionaries and sets.

## Q13. What is the Two Pointer technique?

A technique that uses two indices to process a sequence efficiently.

## Q14. What is Sliding Window?

A technique that maintains a moving range of elements while processing a sequence.

## Q15. What is KMP?

An efficient pattern-matching algorithm using the LPS array.

## Q16. What is LPS?

Longest Proper Prefix which is also a Suffix.

## Q17. What is a substring?

A contiguous sequence of characters inside a string.

## Q18. What is a subsequence?

A sequence formed by deleting zero or more characters without changing the order of remaining characters.

## Q19. Difference between substring and subsequence?

A substring must be continuous; a subsequence does not have to be continuous.

## Q20. Why is dictionary useful in string problems?

It stores character frequencies and provides efficient average-case lookup.

## Q21. What is Unicode?

Unicode is a standard that assigns code points to characters from different writing systems.

## Q22. What is the difference between ord() and chr()?

`ord()` returns a character's Unicode code point, while `chr()` converts a valid code point into a character.

## Q23. What is the complexity of reversing a string using slicing?

$$
O(n)
$$

## Q24. What is the complexity of sorting a string?

$$
O(n \log n)
$$

## Q25. What is the complexity of KMP?

$$
O(n + m)
$$
