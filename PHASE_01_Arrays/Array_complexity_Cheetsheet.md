## 1. Array Complexity Cheat Sheet

| Operation | Time Complexity |
|---|---|
| Access by index | O(1) |
| Update by index | O(1) |
| Traversal | O(n) |
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Append | Amortized O(1) |
| Insert at beginning | O(n) |
| Delete at beginning | O(n) |
| Prefix construction | O(n) |
| Range Sum Query | O(1) after preprocessing |
| Kadane's Algorithm | O(n) |
| Reverse using Two Pointers | O(n) |
| Two Sum on sorted array | O(n) |
| Three Sum | O(n²) |
