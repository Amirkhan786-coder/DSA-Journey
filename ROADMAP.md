# Problem-Solving Strategy

For every important problem:

1. Understand the problem.
2. Identify the pattern.
3. Develop the brute-force approach.
4. Optimize the solution.
5. Write clean code.
6. Test normal and edge cases.
7. Analyze time and space complexity.
8. Document the solution.
9. Revise after some time.

**Problem target:** The number of problems will vary according to topic difficulty, concept coverage, and pattern complexity. No unnecessary fixed limit.

---

# Learning Priority

**Understanding > Pattern Recognition > Consistent Practice > Speed**

**Golden Rule:** Never memorize a solution without understanding its logic and being able to implement it independently.
